# Viral Boost AI

نسخة أولية قابلة للتشغيل على Node.js 18 أو أحدث.

## التشغيل محلياً
```bash
npm start
```
ثم افتح `http://localhost:3000`.

## النشر على Render
1. ارفع محتويات هذا المشروع إلى مستودع GitHub باسم `Viral-Boost-AI`.
2. في Render اختر New > Web Service ثم اربط المستودع.
3. Runtime: Node، Build Command: `npm install`، Start Command: `npm start`.
4. انشر الخدمة.

## ملاحظة مهمة
هذه نسخة أولية تنتج نصوصاً وقوالب وبرومبتات محلياً، وليست متصلة بعد بخدمات توليد الفيديو أو الصوت أو حسابات Meta/TikTok. يلزم اختيار مزوّد API وإضافة مفاتيح سرية في إعدادات الاستضافة قبل تفعيل هذه الوظائف. لا تضع مفاتيح API داخل ملفات الواجهة أو GitHub.
